# Gossipyfy

Gossipyfy is a platform where users can share gossips, news, songs, and podcasts anonymously and monetize their conversations. It combines privacy, creativity, and engagement into a single app.

## Features

- **Anonymous Sharing**: Share gossips and content while keeping your identity private.
- **Monetization**: Users can monetize their conversations.
- **Rich Media**: Supports sharing of news, songs, podcasts, and more.
- **Secure Authentication**: Powered by NextAuth for user authentication.
- **Scalable Storage**: Media files are stored securely on AWS S3.
- **Dynamic UI**: Built with Tailwind CSS and enhanced with Framer Motion for stunning animations.
- **Payment Integration**: Razorpay for seamless transactions.

---

## Tech Stack

- **Frontend**: [Next.js](https://nextjs.org/)
- **Backend**: Node.js
- **Database**: PostgreSQL (via Prisma ORM)
- **Authentication**: NextAuth
- **Storage**: AWS S3
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Payments**: Razorpay
- **Deployment**: Vercel
